🧩 Kokoro API URL & Chrome Extension Guide

Extension: Kokoro TTS Sender (Chrome Web Store) · Connect your running Docker Kokoro container (or Fly.io cloud endpoint) to any OpenAI-compatible Chrome TTS extension in 30 seconds.

🔗 Your Unique Kokoro API URLs

Copy one of the OpenAI-compatible Base URLs below and paste it into your Chrome extension's API Base URL / Endpoint field.

1. Local Docker (kokoro-tts) RECOMMENDED · FASTEST http://127.0.0.1:8880/v1/ Runs offline on your Mac via Docker (ghcr.io/remsky/kokoro-fastapi-cpu) · 67 voices · zero latency.
2. Local Kokoro App (This Server) PORT 30088 · EN + TR http://127.0.0.1:30088/v1/ Local FastAPI app from this repo · supports Kokoro English + Turkish Edge-TTS + OpenAI /v1/audio/speech.
3. Cloud Kokoro (Fly.io) WORKS ANYWHERE https://secondbrain-kokoro.fly.dev/v1/ Hosted on Fly.io · works even when Docker is off · HTTPS ready for strict Chrome extensions.

📖 How to Use the Chrome Extension with Kokoro (Step by Step)

This is what it looks like when it's working: highlight text on any page and the extension's reader panel (top-right) reads it aloud with a Kokoro voice. It shows a progress bar, the time left, and Pause / Prev / Next / Volume / Speed controls.

  1. Install the extension: open Kokoro TTS Sender on the Chrome Web Store, click Add to Chrome, then pin it (🧩 → 📌) so it stays on your toolbar.
  2. Start a Kokoro backend. Pick one:
    • 🐳 Docker (fastest): docker start kokoro-tts → http://127.0.0.1:8880/v1
    • 🖥 This app locally: PORT=30088 venv/bin/python main.py → http://127.0.0.1:30088/v1
    • ☁️ Nothing to start: use Fly.io → https://secondbrain-kokoro.fly.dev/v1 (the first call may take a few seconds while the machine wakes up)
  3. Check it here first. In the Live API Tester below, choose the same URL and click 🔊 Test /v1/audio/speech. If you hear audio, the extension will work too.
  4. Open the extension's settings (click the Kokoro TTS Sender icon, or 🧩 → Kokoro TTS Sender → ⋮ → Options) and choose the OpenAI-compatible / Custom API provider.
  5. Fill in the fields: Base URL = one of the URLs above · API Key = not-needed · Model = kokoro (or tts-1) · Voice = af_heart · Format = mp3. Then save.
  6. Read something: highlight text on any web page, then right-click → Read aloud, or click the extension icon / use its keyboard shortcut. The reader panel opens and starts speaking.
  7. Control playback from the panel: Pause, Prev/Next sentence, volume slider, and speed (e.g. 1.0x).

🛠 If it doesn't speak

  • "Failed to fetch" / connection refused → the backend isn't running. Run docker ps --filter name=kokoro-tts, or switch to the Fly.io URL.
  • Blocked on HTTPS sites → some extensions won't call http:// from HTTPS pages. Use https://secondbrain-kokoro.fly.dev/v1.
  • 404 Not Found → the path got doubled up. Base URL should end in /v1. Only use the full /v1/audio/speech if the field asks for the "speech endpoint".
  • Voice error → use a Kokoro voice ID (af_heart) or an OpenAI name (alloy, nova…). Turkish (tr-TR-EmelNeural) works only on port 30088 / Fly.io, not Docker.

⚙️ What to Paste into Your Chrome Extension

Most Chrome TTS extensions (such as Read Aloud, Kokoro TTS Reader, OpenAI TTS, or custom sidebar readers) ask for an OpenAI-compatible TTS configuration:

Extension FieldValue to EnterNotes
API Base URL http://127.0.0.1:8880/v1 Use http://127.0.0.1:8880/v1/ (or without trailing slash depending on extension). If the extension asks for the full speech path, use http://127.0.0.1:8880/v1/audio/speech.

💡 Quick Tips for Chrome Extensions

  • Use 127.0.0.1 instead of localhost to avoid IPv6 resolution hiccups in Chrome.
  • If an extension refuses http:// (mixed-content restriction on HTTPS pages), switch the Base URL to your Fly.io HTTPS URL: https://secondbrain-kokoro.fly.dev/v1/.
  • Docker Kokoro also includes its own built-in web UI at http://127.0.0.1:8880/web/.

🐳 Docker & cURL Quick Reference

Verify your Docker container is running

docker ps --filter name=kokoro-tts
# Start if stopped:
docker start kokoro-tts

Test the OpenAI-compatible speech endpoint via curl

curl -X POST http://127.0.0.1:8880/v1/audio/speech \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kokoro",
    "input": "Hello from local Kokoro Docker!",
    "voice": "af_heart",
    "response_format": "mp3",
    "speed": 1.0
  }' \
  --output kokoro-test.mp3
